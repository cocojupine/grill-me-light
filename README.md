# Grill Me Light

A light, general-purpose companion to Grill Me for Codex. It retains the
decision-tree and frontier approach, while asking only the most useful part of
the frontier and allowing branches to be decided, parked, pruned, or left open.

## Install

Copy both folders into `~/.codex/skills`, then start a new Codex task.

## Use

```text
$grill-me-light Help me think through this idea.
```
